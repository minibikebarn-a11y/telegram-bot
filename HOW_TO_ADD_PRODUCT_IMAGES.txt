HOW TO ADD PRODUCT IMAGES TO THE BOT
=====================================

1. Create a folder called "images" inside the bot folder (same folder as "conf").
   Path: little bit\images\

2. Save each product image as a .jpg file using EXACTLY the filename listed below.
   The filenames must be lowercase with underscores — no spaces, no emojis.

3. The bot will automatically pick up each image the first time that product is viewed.
   No restart needed after adding images to the folder.

NOTES
----------------------------------------------------------------------

- Images that are missing are skipped — the product still shows with the
  default menu image. You can add images one at a time at any point.

- Recommended size: 800x800 px or larger, square crop works best in Telegram.

- Once the bot sends an image to Telegram it caches the file ID in memory,
  so subsequent views of the same product are instant. The cache resets
  on bot restart, but the image is re-uploaded automatically.

- If a product image looks wrong, delete the file and save the correct one
  with the same filename, then restart the bot to clear the cache.
